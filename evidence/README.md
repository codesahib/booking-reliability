Reproduce from the repo root after installing dependencies, with task servers stopped:

```bash
source .venv/bin/activate
bash scripts/verify.sh --ui
# Or, when using installed Chrome:
PLAYWRIGHT_CHANNEL=chrome bash scripts/verify.sh --ui
```

The script regenerates comparison/check output and browser screenshots. Timestamps and new booking IDs naturally differ; fixture business assertions are deterministic. `diagnosis.json`, provenance, and selected log samples preserve their original captured phase evidence rather than being silently rewritten by the verification script.

No human debugging duration, detection latency percentile, production performance, customer data, or payment integration is represented by these artifacts. Full failure traces are transient test artifacts under ignored `test-results/`; corrected failures and limitations are documented in the results/process notes.
